# ❤️ Heart Disease Prediction

A Machine Learning-based web application that predicts the likelihood of **Heart Disease** using patient health and clinical parameters. The project uses **Logistic Regression** with Scikit-learn and provides an interactive prediction interface built with **Streamlit**.

> **Note:** This project is intended for educational and demonstration purposes only. It is not a substitute for professional medical diagnosis.

---

## 🚀 Project Overview

The goal of this project is to build a classification model that can identify whether a patient is likely to have heart disease based on selected health-related attributes.

The project covers the complete Machine Learning workflow:

* Data preprocessing
* Categorical feature encoding
* Feature scaling
* Model training
* Model evaluation
* Model comparison
* Model serialization using Joblib
* Streamlit application development
* Real-time predictions

---

## 🧠 Machine Learning Model

Several classification algorithms were evaluated during the project:

| Model               |   Accuracy |   F1 Score |
| ------------------- | ---------: | ---------: |
| Logistic Regression | **85.87%** | **87.38%** |
| KNN                 |     85.33% |     87.08% |
| Decision Tree       |     79.89% |     81.59% |
| Random Forest       |     86.41% |     88.37% |
| SVM (RBF Kernel)    |     84.78% |     86.79% |
| Naive Bayes         |     84.78% |     86.14% |

Although Random Forest achieved slightly higher evaluation scores, **Logistic Regression was selected for deployment** because of its strong performance and simplicity.

### Selected Model

**Logistic Regression**

* Accuracy: **85.87%**
* F1 Score: **87.38%**

## 📊 Features Used

The model uses the following patient attributes:

* Age
* Sex
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Maximum Heart Rate
* Oldpeak
* Chest Pain Type
* Resting ECG
* Exercise-Induced Angina
* ST Slope

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/heart-disease-prediction.git
```

### 2. Navigate to the project directory

```bash
cd heart-disease-prediction
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in your browser.

---

## 💻 How It Works

1. User enters the required patient health information.
2. The application converts categorical inputs into the required numerical features.
3. The input data is arranged according to the model's expected feature columns.
4. The data is scaled using the saved preprocessing scaler.
5. The trained Logistic Regression model generates a prediction.
6. The Streamlit interface displays the prediction and model probability.
